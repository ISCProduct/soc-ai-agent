# Cubism 引き継ぎチェックリスト

## 男性・女性共通

- [ ] 顔輪郭、前髪、後ろ髪、左右眉、左右白目、左右虹彩、左右上まぶた、左右下まぶたを分離
- [ ] 上唇、下唇、口内を分離
- [ ] 首、シャツ／ブラウス、上着、ネクタイ（男性）を分離
- [ ] 顔、髪、首、上半身にデフォーマを設定
- [ ] `ParamMouthOpenY` 0=閉口、1=開口
- [ ] `ParamEyeLOpen` / `ParamEyeROpen` 0=閉眼、1=開眼
- [ ] `ParamAngleY` -30〜30で自然な上下うなずき
- [ ] `LipSync` に `ParamMouthOpenY` を登録
- [ ] `EyeBlink` に左右の目開閉を登録
- [ ] 2048pxアトラス1枚、余白2px以上
- [ ] MOC3書き出し時に表示補助ファイル（`.cdi3.json`）を出力
- [ ] 編集用 `.cmo3` を保存
- [ ] `npm run check:live2d -- <directory>` が成功
- [ ] `/interview` の96〜120px枠で閉眼、開口、うなずきを目視確認

## 現在の不足

この素材パッケージにはCubism Editorでのみ生成できる `.cmo3`、`.moc3`、テクスチャアトラス、
`.model3.json`、`.cdi3.json` はまだ含まれていません。これらを生成するまではランタイムモデルとして配置しないでください。
