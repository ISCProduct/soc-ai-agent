# Cubism 引き継ぎチェックリスト

## 男性・女性共通

- [ ] 顔輪郭、前髪、後ろ髪、左右眉、左右白目、左右虹彩、左右上まぶた、左右下まぶたを分離
- [ ] 上唇、下唇、口内を分離
- [ ] 首、シャツ／ブラウス、上着、ネクタイ（男性）を分離
- [ ] 顔、髪、首、上半身にデフォーマを設定
- [ ] `ParamMouthOpenY` 0=閉口、1=開口
- [ ] `ParamEyeLOpen` / `ParamEyeROpen` 0=閉眼、1=開眼
- [ ] `ParamAngleY` -30〜30で自然な上下うなずき
- [ ] `LipSync` に `ParamMouthOpenY` を登録
- [ ] `EyeBlink` に左右の目開閉を登録
- [ ] 2048pxアトラス1枚、余白2px以上
- [ ] MOC3書き出し時に表示補助ファイル（`.cdi3.json`）を出力
- [ ] 編集用 `.cmo3` を保存
- [ ] `npm run check:live2d -- <directory>` が成功（終了コード0。3 は「cdi3 が無く未確認」で合格ではない）
- [ ] `/interview` の96〜120px枠で閉眼、開口、うなずきを目視確認
- [ ] `/interview` の16:9ステージ（アバターは全面表示）で顔が切れていないことを確認
- [ ] 同ステージで、右上のPiPと下部の字幕（3行のとき）が口と目を覆っていないことを確認
- [ ] 接続中・エラーのオーバーレイが出た状態でも上の2点が崩れないことを確認
- [ ] ステージ幅 375px / 768px / 1440px の3段で上の2点を確認

`check:live2d` はパラメータの能力しか見ない。ステージ上の見え方（顔の収まり、
オーバーレイとの重なり）は自動で検査できないので、採用前に必ず実画面で確認する。

## 現在の不足

この素材パッケージにはCubism Editorでのみ生成できる `.cmo3`、`.moc3`、テクスチャアトラス、
`.model3.json`、`.cdi3.json` はまだ含まれていません。これらを生成するまではランタイムモデルとして配置しないでください。
