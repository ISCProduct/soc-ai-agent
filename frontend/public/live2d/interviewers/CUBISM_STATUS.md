## 未完了のもの

- **口・まばたきの動作（Cubism側。最優先）**: 男性モデルは、コード側（`frontend/lib/interview/live2d-overlay.ts`）が差分 ArtMesh（`ArtMesh0`=目閉じ、`ArtMesh1`=口開き）の不透明度を毎フレーム上書きして動かしており、実画面で口パク・まばたきを確認済み（2026-10-29）。これは暫定対応で、書き出しを直したら不要になる。再書き出しで ArtMesh の ID が変わると動かなくなるので注意。以下は、書き出し済み `.moc3` 自体の問題（2026-10-28 の確認）。
  - 実画面での確認（2026-10-28）で、男女とも動かなかった。待機中と発話中のスクリーンショットがピクセル単位で同一。Cubism Core でパラメータを 0 / 1 に振っても、描画パーツの不透明度が変わらない（男性は3枚とも常に 1.0 で、口開き差分が常時表示される。女性は1枚のみ）。パラメータは定義されているが、描画へのキーフォームが書き出し済み `.moc3` に入っていない。
  - 男性: 口開き差分の不透明度を `ParamMouthOpenY`（0 → 0、1 → 1）に、目閉じ差分を `ParamEyeLOpen` / `ParamEyeROpen`（1 → 0、0 → 1）にキー設定し、再書き出しする。
  - 女性: 目・口の差分を追加してから、同様にキー設定する。
- 女性モデルのテクスチャアトラスの 2048 px 化（現在は 1024 px。男性は 2048 px で書き出し済み）
