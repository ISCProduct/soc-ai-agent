# Pull Request の作成

`$pr <Backlog 課題キー・GitHub Issue 番号>` で、実装済みの変更の PR を作る。引数がなく関連課題が差分やコミットから分かる場合は、その課題を使う。

1. 作業ブランチ、対象差分、未コミット変更、既存 PR を確認する。コミットが必要なら今回の変更だけを対象にし、無関係な変更が混ざっていないことを確かめる。
2. `CLAUDE.md` のブランチ運用に従い、通常の変更は `develop` をベースにする。実際のベースとの差分を読み、概要、変更点、検証結果を日本語でまとめる。
3. ブランチを push し、PR がなければ作成する。Backlog キーがある場合はタイトルに含める。関連する GitHub Issue があり、この PR で解決する場合は本文に `Closes #番号` を記す。
4. 作成した PR の URL と検証結果を報告する。
