# Pull Request の作成

`$pr <Backlog 課題キー | GitHub Issue 番号>` で、実装済みの SOC AI Agent の変更から PR を作る。

1. 作業ブランチ、対象差分、未コミット変更、既存 PR を確認する。
2. 対応する Backlog 課題キー `SOCAIAGENT-<番号>` を確定する。キーが指定されていればその課題を確認する。GitHub Issue 番号が指定されていれば、Issue のタイトル・本文から対応するキーを確認する。引数なしの場合は、既存 PR、ブランチ名、今回のコミットにあるキーを手がかりにする。番号だけから Backlog キーを推測しない。対応する課題が見つからない場合や候補が複数で特定できない場合は、push や PR 作成に進む前に課題キーを確認する。
3. `CLAUDE.md` のブランチ運用に従い、通常の変更は `develop` をベースにする。実際のベースとの差分から概要、変更点、検証結果を日本語でまとめる。コミットが必要なら今回の変更だけを対象にする。
4. ブランチを push し、PR がなければ `[SOCAIAGENT-<番号>]` をタイトルに含めて作成する。既存 PR にキーが欠けている場合は、確認済みのキーをタイトルに追記する。関連する GitHub Issue があり、この PR で解決する場合は本文に `Closes #番号` を記す。
5. PR の URL、Backlog キー、検証結果を報告する。
