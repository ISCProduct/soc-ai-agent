## プルリクレビュー確認（レビュー者が記入）

以下の項目を確認用に使う。チェック済みとして報告するのは実際に確認できた項目に限る。対象外の言語規約は適用しない。
1. コードの基本品質
   1. コードの可読性
      - [ ] 変数・関数名は適切か（意味が明確で、一貫性があるか）
      - [ ] 関数が肥大化していないか (複数の役割を詰め込んでいないか)
      - [ ] public, protected, private 修飾子は適切か
      - [ ] コメントは適切に記述されているか（不要なコメントは削除されているか、実装にそぐわないコメントが無いか）
      - [ ] インデントやスペースなどのフォーマットが統一されているか（PSR2 PSR12, PrettierやESLintを活用）
      - [ ] 使われなくなったメソッドやクラスが残っていないか
   2. コードの設計
      - [ ] 過度にネストされたコード（if文・ループなど）がないか

2. 機能・ロジックの確認
   - [ ] 無駄な処理を行っていないか（不要なループ、無駄な計算）
   - [ ] 必要な場合は非同期処理（async/await、Promise）を適用しているか

3. セキュリティ
   - [ ] ユーザの権限に応じた画面表示になっているか (管理画面) ロールの権限

4. バックエンド（該当する場合）
   - [ ] データベースのインデックスが適切に設定されているか

5. テスト
   - [ ] テストケースは適切か（正常系・異常系・境界値を考慮）
