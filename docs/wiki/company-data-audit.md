# 企業データの点検と一括修正

既存の `companies` を、取得時の正規化(`sanitizeCompanyInfo`)と近い基準で点検し、必要なら直すコマンド。
取得時の正規化は新規取得分にしか効かないため、すでに DB にある値の表記ゆれはこれで確認・修正する(SOCAIAGENT-326)。

## 使い方

```bash
cd Backend
# 点検のみ(既定。何も書き込まない)
go run ./cmd/company-audit
# 修正を適用(適用前の値を before.json に保存してから、1トランザクションで更新)
go run ./cmd/company-audit --apply --backup /tmp/company-before-YYYYMMDD.json
# 元の値へ戻す
go run ./cmd/company-audit --restore /tmp/company-before-YYYYMMDD.json
```

接続先は `DB_HOST` / `DB_PORT` / `DB_USER` / `DB_PASSWORD` / `DB_NAME`(`cmd/migrate` と同じ)。実行のたびに接続先(ホスト・DB名・`APP_ENV`)を最初に表示する。

### backup の保管

backup は**元の値を戻せる唯一の入力**で、`--restore` はこれしか読まない。リポジトリ外(`/tmp` など)に書いて誤コミットを防ぐが、`/tmp` は再起動やコンテナの作り直しで消えるため、**適用したらその場で消えない場所へ写す**。

```bash
go run ./cmd/company-audit --apply --backup /tmp/company-before-20261101.json
# 適用できたら、消えない場所へ写してから /tmp を信用しない
cp /tmp/company-before-20261101.json ~/soc-ai-agent-backups/
```

写し終わるまで元のファイルを消さない。**戻す必要がないと確認できるまで保管する**(これを失うと、適用前の値はどこにも残らない)。

## 出力

- `industry` と `work_style` の値ごとの件数(industry は選択肢そのものなら「正規」、それ以外は「ゆれ」)
- 修正対象の企業と、変更前→変更後
- 選択肢に寄せられず**そのまま残す**値(要判断)

値は `%q` で表示する(前後の空白や改行を見分けるため)。論理削除された企業は対象外。

## 何を直すか

- 業種: 表記ゆれを選択肢へ寄せる(例: 情報・通信業 → IT・ソフトウェア)。空白だけの値は空にする。
- 勤務スタイル: リモート/出社の語から寄せる(例: 週3リモート週2出社 → ハイブリッド)。
  **否定表現(不要・不可・なし 等)を含む値は寄せず、要判断として残す**(「出社不要」をオフィスにする取り違えを避ける)。
- 設立年(1800未満・翌年より先)、従業員数(負・300万超)は0にする。0になった従業員数の `employee_count_basis` も空にする。
- 公式サイトURL: 前後の空白だけ落とす。`http(s)://` で始まらない値(`www.` 始まり等)は**消さず要判断として残す**(大文字スキームは有効として残す)。

**取得時との違い:** 取得時は寄せられない値を空にするが、既存データの一括修正では**空にせず残して報告する**(元の情報を失わないため)。
残った値は一覧を見て、`industryAliases` への追加か手修正を判断する。

## 安全策

- `--apply` には `--backup` が必須。ファイルを書き出せなければ適用しない。**既存ファイルは上書きせず失敗する**(前回の戻し用データを消さない)。
- 更新は1トランザクションで、**読み込み時の値のままの行だけ**を更新する。
  読み込み後に管理画面や再取得ジョブが同じ列を更新していたら、その行を含めて全件ロールバックする。
- `--restore` も同じ条件(現在値が適用後のままの行だけ戻す)。適用後に手で直された値は巻き戻さない。
- `APP_ENV` が `production` / `prod`、または `DB_HOST` が localhost 以外のときは、書き込みに `--allow-production` が必要。
  **SSM のポートフォワードなどで localhost の先が本番でも、自動では見分けられない。** 書き込む前に表示される接続先を必ず確認する。
- 再実行しても結果は変わらない(2回目の修正対象は0社)。
- 戻しは `updated_at` を更新しない(このコマンドは `updated_at` を触らない)。
