# 履歴書・ES のひな形と例文（SOCAIAGENT-613 / #2023）

ES の添削・リライトは書いた文章が前提で、白紙から書き出す学生を助けられなかった。
設問の種類ごとに、書く順番・書き出し・ひな形・例文を出し、入力欄へ入れられるようにする。

## 画面

ES 添削・リライト（`/es-rewrite`）の「質問種別」の下に「書き出しガイドと例文」を置く（`components/es/EsTemplatePanel.tsx`）。

- 入力欄が空なら開いた状態、書きかけなら閉じた状態で始まる
- 書く順番 → 書き出しの例 → ひな形 → 例文（絞り込みつき）の順に出す
- 「入力欄に入れる」: 空なら置き換え、書きかけなら末尾に足す（書いた文章は消さない）。入力欄の上限（6,000字）を超えるなら入れずに知らせる
- 質問種別を変えると、例文の絞り込みも戻す
- 本文に【 】が残っていたら、送る前に「自分の経験に置き換えてから送って」と警告する（送信は止めない）

## 辞書（`lib/es-templates.ts`）

AI は使わない静的な辞書（OpenAI が使えなくても動く）。AI による補完（任意）は入れていない。

| 設問の種類 | 例文の絞り込み | 例文の数 |
|---|---|---|
| 志望動機 | 業界（IT・ソフトウェア／メーカー／金融／商社・小売／サービス・医療福祉） | 5 |
| 自己PR | 職種（エンジニア・技術職／営業／事務・管理／販売・接客／企画・クリエイティブ） | 5 |
| 学チカ・ガクチカ（同じガイド） | 経験の種類（アルバイト／部活動・サークル／研究・ゼミ／資格・学習／チームでの制作・開発） | 5 |
| その他 | なし（書く順番・書き出し・ひな形だけ） | 0 |

- 例文は書き方の「型」を見せるためのもの。固有の内容（会社の特徴・数字・経験）は【 】で空けておき、自分の経験で埋める。
  そのまま提出させないよう、画面にも注記する
- 例文は 400 字程度に収める（テストで確かめる）
- 履歴書の自己PR・志望動機の欄も、同じ種類のガイドがそのまま使える

## 例文を足すとき

`ES_GUIDES` の該当する種類の `examples` に `{ tag, title, text }` を足す。`text` には【 】を必ず1つ以上入れる。
`tag` は絞り込みの値で、同じ値の例文はまとめて出る。
