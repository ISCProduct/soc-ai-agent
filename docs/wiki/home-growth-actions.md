# 診断スコアに応じた改善の提案（ホームの「次にやること」、SOCAIAGENT-614 / #2022）

ホームの「次にやること」（#1576）は予定と応募だけで、診断の結果とつながっていなかった。
診断・面接の状況と、低めの傾向に応じた練習の提案を足す。

## データ

Backend は変えていない。既存の `GET /api/portfolio?sections=diagnosis,interview`（本人のみ）から次を取る。

- 最新の診断の10カテゴリのスコア（面接だけで決まったスコアは含まない。#2235）
- AI 面接のレポートの件数（最新3件まで。0 なら未着手）

取得に失敗しても、予定・応募の表示は止めない（改善の提案を出さないだけ）。

## 提案の規則（`lib/next-actions.ts`）

| 提案 | 条件 | 行き先 |
|---|---|---|
| AI 診断を始める | 診断のスコアが無い | なし（ホームのチャットで進めるのでボタンを出さない） |
| 低めの傾向を練習する | 練習の対象のカテゴリが4つ以上測れていて、いちばん低いものが50未満 | 面接（`/interview`）か ES（`/es-rewrite`） |
| AI 面接を練習する | 面接のレポートが0件 | `/interview` |

- 練習の対象と行き先（`CATEGORY_PRACTICE`）
  - 面接: コミュニケーション力・リーダーシップ志向・チームワーク志向・チャレンジ志向（話して伝える経験）
  - ES: 技術志向・創造性志向・細部志向・成長志向（経験を言葉にして書く）
- **安定志向・ワークライフバランスは働き方の好み**で、低いことが弱みではないので対象にしない
- 同じ点なら `CATEGORY_PRACTICE` の並び順で先のもの

## 並び

直近の予定 → 内定の返事 → 診断・面接の改善の提案 → 応募するか未決の企業。
期限のあるものを先に出す。帯は1行なので、先頭の1件と「ほか N 件」だけ出す（#1763）。
