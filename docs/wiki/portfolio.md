# 自己分析ポートフォリオ（#2030）

学生が、診断・AI 面接・ES 添削・適性検査の結果を1つにまとめ、就職活動の提出や振り返りに使う。
画面は `/portfolio`（プロフィール画面から開く）。ブラウザの印刷で PDF にする。

## 内容

| セクション | 中身 | 件数 |
|---|---|---|
| 適性の診断（`diagnosis`） | 最新の診断の10カテゴリのスコア（高い順）。`FindLatestByUser` と同じ「最新セッション」 | 1件 |
| AI 面接（`interview`） | 終了済みでレポートのある面接の要約・強み・改善点。**教員向けの詳細（`teacher_report_json`）は含めない** | 最新3回 |
| ES 添削（`es`） | 設問・企業名・各スコア・フィードバック。ES の本文は長いので含めない | 最新5件 |
| 適性検査（`assessment`） | 学校の適性検査の結果（カテゴリ別のスコア） | 最新3回 |

## API

`GET /api/portfolio?sections=diagnosis,interview,es,assessment`（空なら全部、知らない値は無視、全部知らない値なら 400）。

- 宛先は `EchoUserAuth`（`X-User-Token`）から決め、`user_id` はクエリから受け取らない。どのクエリも本人の `user_id` で絞る
- 個人情報を含むので `Cache-Control: no-store`
- 削除した面接（`deleted_at`）と未終了の面接は除く

## 共有リンクは作らない

Issue の「PDF または共有リンク」のうち、PDF（ブラウザの印刷）だけにした。共有リンクは学生の個人情報を
認証なしで見られる URL になるため。外部へ渡すときは、学生が PDF を自分で渡す。
