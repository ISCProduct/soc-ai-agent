# 機能横断のコンバージョンファネル（#2039）

管理画面のダッシュボード（`/admin/dashboard`）に、学生がどの段階で止まっているかを出す。
API は `GET /api/admin/dashboard/funnel?school_id=&from=YYYY-MM-DD&to=YYYY-MM-DD`。

## 段階の定義

| 段階 | 到達とみなす条件 | 期間を見る日時 |
|---|---|---|
| 診断 | AI 診断チャットで回答した（`chat_messages` の `role=user`）、または学校の診断を提出した（`assessment_sessions.submitted_at`） | 発言日時・提出日時 |
| 面接練習 | AI 面接を最後まで終えた（`interview_sessions.status=finished`） | 開始日時 |
| ES 添削 | ES の添削を受けた（`es_reviews`） | 添削日時 |
| 応募 | 選考ステータスが応募済み以降（`not_applied` 以外） | 応募日（無ければ登録日時） |
| 内定 | 選考ステータスが内定・内定承諾（`offered` / `accepted`） | ステータスの最終更新日（無ければ更新日時） |

- 対象の学生（母数）は、退会していない学生（`role=student`、管理者を除く）。期間で母数は絞らない
- 各段階の数字
  - **到達人数**: その段階に到達した学生の数（前の段階を経たかは問わない）
  - **対象の学生に対する割合**: 到達人数 / 対象の学生
  - **前の段階からの継続率**: 前の段階に到達した学生のうち、この段階にも到達した割合。面接練習をせずに応募する学生もいるので、到達人数どうしの比ではなくこの形にして、100% を超えないようにしている
- 期間は日本時間の日付で、開始日・終了日の両方を含む

## 認可

担当校スコープ（`EchoAdminSchoolScope`）の下に置く。担当校を持つ管理者・職員は `school_id` が必須で、担当校以外は 403。
担当校を持たないシステム管理者だけが、`school_id` なしで全体を見られる。どの段階も、対象の学生（その学校の学生）で絞ってから数える。

## 制約

- **クラス別は未対応**: ユーザーにクラスの項目が無いため、学校別までにしている。クラス別にするには、クラスの項目の追加（migration）が要る
- **内定後の辞退**: 選考ステータスは履歴を持たないので、内定のあと辞退した学生（`withdrawn`）は内定に数えられない
