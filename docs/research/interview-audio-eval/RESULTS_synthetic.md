# 合成音声によるSTTモデル比較（Phase 0/1）

- 実行日: 2026-09-09
- データ: `manifest.jsonl` の8ケース（WAV 16kHz mono、合計 93.9秒）
- ツール: `Backend/cmd/sttbench`
- 実行: `go run ./cmd/sttbench -manifest ../docs/research/interview-audio-eval/manifest.jsonl -format wav -out <リポジトリ外>`

## 結果

| モデル | 平均CER | 意味CER | 固有名詞 | 数値 | 失敗率 | $/面接(発話10分) |
|---|---|---|---|---|---|---|
| gpt-4o-transcribe | 0.017 | **0.010** | 92.3% | 100% | 0% | $0.0600 |
| gpt-4o-mini-transcribe | 0.018 | **0.011** | 92.3% | 100% | 0% | **$0.0300** |

**この8ケースでは、両モデルに実質的な差はありませんでした。**

## 検出された差分のすべて

| ケース | 正解 | 認識 | モデル | 性質 |
|---|---|---|---|---|
| clean-introduction | Webアプリケーション | ウェブアプリケーション | 両方 | 表記ゆれ |
| numbers-and-results | 30パーセント | 30% | 両方 | 表記ゆれ |
| long-answer | やり切る | やりきる | mini のみ | 送り仮名 |

**固有名詞（Go / AWS / Docker / MySQL / 御社 / バックエンドエンジニア 等）と数値（120時間 / 30）は、両モデルとも全て正解**しました。

## この結果で判断してはいけないこと

**合成音声のみの結果です。** README にあるとおり、発音・雑音・個人差を再現していません。

- 人間の発話、雑音、反響、小声、早口、言い淀みは含まれていません
- 8ケースは母数として小さく、固有名詞は13語しかありません
- 端末差（ノートPC / スマートフォン / 外付けマイク）も未検証です

**mini への切り替え可否は、実発話（Phase 2）を測るまで決められません。**
本結果が言えるのは「合成音声の範囲では差が出なかった」までです。

## 計測時に見つかった評価側の問題

初回の実行では固有名詞の正解率が **60%** と出ましたが、これは**計測の誤り**でした。

1. `manifest.jsonl` の `checks` に、実際に発話へ現れる語（`Go`, `MySQL`）と、
   評価観点のラベル（`一般語`, `言い淀み`, `無音区間`）が混在している。
   ラベルまで照合すると、現れるはずのない語を不正解として数える。
   → 正解文に含まれる語だけを照合対象とするよう修正（`CheckableKeywords`）
2. 表記ゆれ（`30パーセント` → `30%`）を誤変換として数えると、CERが 0.08 に跳ねる。
   → 意味の差を見る `SemanticCER` を別指標として追加

**指標の作り方次第で「miniは精度が低い」という誤った結論になり得ました。**
評価基盤そのものを検証してから数値を読むこと。
