# AWS コスト概算（ECS on EC2 + RDS + S3 + Route53）

最終更新: 2026-08-03  
リージョン: `ap-northeast-1`（東京）  
コンピュート: **ECS on EC2**（Fargate ではない）  
為替目安: **$1 ≒ ¥150**（変動するため参考値）

> これはオンデマンド・低〜中トラフィック前提の概算です。  
> 確定見積は [AWS Pricing Calculator](https://calculator.aws/) で再計算してください。  
> OpenAI / Resend 等の外部 SaaS 料金は含みません。

関連: #648（インフラ）、実装計画（チャット上の Phase 0〜5）

## 3. 月額内訳（最小検証・NAT なし）

ECS EC2 を **public subnet** に置き、NAT Gateway を省略した場合。

| 項目 | USD/月 | JPY/月 |
|------|--------|--------|
| 上記小計（NAT あり） | 127 | 19,200 |
| NAT Gateway + NAT データ処理を除外 | −48.36 | −7,300 |
| **小計（NAT なし）** | **≈ 79** | **≈ 11,900** |

**計上レンジ: $65〜110 / 月（約 ¥10,000〜17,000）**

コスト優先の初期検証ではこちらを推奨。

## 6. コストドライバー（大きい順）

1. **NAT Gateway** … 固定で約 $45/月。省略可否が最大の分岐  
2. **ALB** … 約 $20〜30/月（HTTPS 本番にはほぼ必須）  
3. **EC2 / RDS** … インスタンスタイプで線形に増減  
4. **CloudWatch Logs / 転送** … 運用・トラフィック次第で膨張  

ECS の「クラスター料金」自体は **$0**。

---

## 7. 含めないもの（別計上）

| 費目 | 理由 |
|------|------|
| OpenAI / Realtime API | 利用量依存（アプリ原価） |
| Resend | メール通数依存 |
| ドメイン取得・更新 | レジストラ料金 |
| Fargate | 本構成では未使用 |
| rag / chroma / company-graph | 後続フェーズ |
| Multi-AZ NAT（AZごと） | 初期対象外（+約 $45×追加分） |
